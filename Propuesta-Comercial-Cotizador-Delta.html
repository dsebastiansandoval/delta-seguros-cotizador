Cotizador Delta: de macro de Excel a plataforma web

Propuesta de desarrollo por fases, con integración de APIs de aseguradoras
Presentado a
Diego Viera — Delta Seguros Cía. Ltda.

Diego: adjunto la propuesta para llevar el cotizador de vehículos y salud que hoy vive en COTIZADOR DELTA.xlsm a una plataforma web multiusuario, con el mismo nivel de detalle que maneja el archivo actual (13 aseguradoras de autos, 8 de salud, carátulas y bases de gestión) y, en una fase posterior, cotización en tiempo real vía API con cada aseguradora. Ya preparé una vista previa visual del producto para que la revisemos juntos antes de entrar en alcance y presupuesto.

01

Situación actual

El archivo COTIZADOR DELTA.xlsm (30 hojas, macros VBA) es hoy el motor comercial de la operación: arma la comparación entre aseguradoras, genera la carátula que se envía al cliente y lleva el control de emisiones, comisiones, pendientes y siniestros. Funciona, pero tiene límites estructurales que un archivo de Excel no puede resolver:

Hoy — Excel con macros
  • Un solo usuario a la vez; se pisan cambios entre ejecutivos
  • Tasas y coberturas de cada aseguradora se digitan a mano
  • La carátula se arma copiando y pegando entre hojas
  • Sin historial de clientes ni trazabilidad por ejecutivo
  • El archivo (5+ MB) se envía por correo o WhatsApp
  • Riesgo real de pérdida o corrupción del archivo maestro
Propuesto — Cotizador Delta web
  • Multiusuario, con roles por ejecutivo y permisos
  • Fase 1: misma carga manual, centralizada en la nube
  • Fase 4: tasas en tiempo real vía API por aseguradora
  • Carátula y oferta se generan en PDF con un clic
  • Historial de clientes, pólizas y renovaciones
  • Acceso desde cualquier equipo, con respaldo automático
02

Alcance funcional

La plataforma replica —y ordena— lo que hoy hacen las hojas del Excel:

  • Autos: datos de cliente y vehículo (como «DATOS VH»), comparador de 13 aseguradoras con coberturas, deducibles y formas de pago (como «OFERTA» / «DATOS OFERTA»), carátula de oferta en PDF (como «CARÁTULA»).
  • Salud (AM): el mismo flujo para BMI, Humana, SaludSA, Confiamed, Bupa, Pro, VB y Salud.
  • Gestión interna: emisiones, pólizas pendientes, comisiones por aseguradora, cancelaciones y siniestros — hoy dispersos en 6 hojas «BASE».
  • Integraciones API: conexión directa con las aseguradoras que ofrezcan canal técnico, para traer tasas y emitir sin digitación manual.
